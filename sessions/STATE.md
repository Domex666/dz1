## Известные проблемы

- **Отступление от задания: Docker.** Задание запрещает его прямым текстом.
  Решение владельца проекта, границы описаны в `SPEC.md`. Риск для оценки:
  критерий «поднимается строго по README» теперь зависит от наличия Docker
  у проверяющего. Смягчено — в README есть и вариант с локальным PHP 8.4.
- **Наивный прогон сделан в той же сессии**, где уже обсуждалась спека.
  Изоляция слабее требуемой, отмечено в `naive/README.md`.
- **Блокировка берётся на файл целиком** — любая запись сериализует остальные.
- **Пагинации нет**, список отдаётся целиком.
- **Конкурентная запись проверена только логикой `flock`**, нагрузочного теста нет.
- **Границы длин человеком не подтверждены.**
