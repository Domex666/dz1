# Наивный прогон

Снапшот первого результата. **Ничего здесь не исправляется**, даже очевидные дефекты —
иначе сравнивать будет не с чем.

## Как получен

Один короткий промпт, без спецификации и без файла правил:

> Сделай на PHP небольшой API для заметок с тегами. Хранилище — файл. Нужен CRUD,
> фильтр по тегам и топ тегов.

## Честная оговорка про изоляцию

Прогон выполнен той же моделью в той же сессии, где уже обсуждалась спецификация.
Это **более слабая изоляция**, чем чистая сессия: полностью «забыть» контекст модель
не может, и наивный вариант мог получиться чуть лучше настоящего наивного.
То есть разница между двумя прогонами в реальности скорее больше, чем показано,
а не меньше.

Правильнее было бы выполнить его в отдельной сессии до начала обсуждения.
Записано как методическая ошибка, а не замаскировано.

Один файл `index.php` на 130 строк: роутер, валидация, чтение файла и формат ответа —
всё в одном месте. Разбор расхождений с итоговым вариантом — в `README.md` в корне.
